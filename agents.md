# agents.md – Anweisungen für den Coding-Agenten

## Projekt
Konsolen-Textadventure "Die Taverne" in Java. Ziel und Features stehen in readme.md und features.md.
Arbeite Features in der Reihenfolge aus features.md ab.

## Pflicht-Einschränkungen
The project should use structured programming in Java including records or simple classes.
No abstractions, inheritance, Collections or other higher level Java features may be used.

Konkret:
- Keine Vererbung (`extends`), keine Interfaces, keine abstrakten Klassen.
- Keine Collections (kein List, ArrayList, Map, Set usw.) – nur Arrays.
- Keine Streams, keine Lambdas, keine Generics.
- Erlaubt: Records, einfache Klassen, statische Methoden, Arrays, Schleifen, if/else, switch, Scanner.

## Code-Stil
- Kurze, gut benannte statische Methoden (eine Aufgabe pro Methode).
- Struktur: Eingabe → Verarbeitung → Ausgabe.
- Ungültige Benutzereingaben immer abfangen.
- Kommentare auf Deutsch, Bezeichner auf Englisch.

## Vorgehen
- Vor größeren Features kurz planen und die Schritte nennen.
- Nach jeder Änderung prüfen, dass das Programm kompiliert und läuft.
- Fertige Features in features.md mit ✅ vor der Nummer markieren.
- Keine Dateien außerhalb des Projekts ändern.
