# Die Taverne – ein Java-Textadventure

Autor: Gregor Zadrazil (FH Technikum Wien, Wirtschaftsinformatik, Gruppe 3)
Lehrveranstaltung: Structured Programming Lab

## Beschreibung
Die Taverne ist ein kleines Textadventure für die Konsole. Der Spieler wacht nach einer
langen Nacht in einer alten Taverne auf und muss den verlorenen Schlüssel zur Haustür finden,
um zu entkommen. Dazu bewegt er sich zwischen Räumen (Schankraum, Küche, Keller, Gästezimmer,
Hof), sammelt Gegenstände, spricht mit dem Wirt und löst kleine Rätsel.

## Starten
1. Projekt in IntelliJ öffnen.
2. `src/Main.java` ausführen (ab Woche 8).
3. Befehle in die Konsole eingeben, z. B. `gehe norden`, `nimm kerze`, `inventar`, `hilfe`.

## Technik
- Java, strukturierte Programmierung
- Records bzw. einfache Klassen für Spieler, Raum und Gegenstand
- Daten in Arrays, Eingabe über `Scanner`
- Keine Vererbung, keine Abstraktionen, keine Collections
